# Omniwebora — end-to-end website governance kit

The package contains five markdown directives and a reference folder with the supplied eight-page scanned brochure, the current-site screenshots, and the original desired hero reference.

## What to do
1. Extract this ZIP into the existing Omniwebora website project root. Do not delete the project or overwrite running work.
2. Connect Higgsfield to Claude Code using your own working MCP/CLI/skills setup. The package **does not** include credentials, MCP installation commands, or API keys.
3. Open Claude Code in the website root.
4. Paste the following:

> Execute `04_CLAUDE_CODE_GOVERNOR_MASTER_PROMPT.md` as your governing directive. Read `01_SOURCE_TRUTH_AND_DECISION_REGISTER.md`, `02_FINAL_CONTENT_AND_SITEMAP.md`, `03_MOTION_AND_VISUAL_SYSTEM.md`, `05_SCREENSHOT_AUDIT_AND_ACCEPTANCE_MATRIX.md`, the supplied scanned brochure and all current/reference screenshots in full. Prioritize final content architecture and factual accuracy BEFORE generation. Preserve existing successful Higgsfield hero and scroll scenes. Rebuild weak home sections and all interior routes into unique mature, sophisticated, meaningful experiences with real interactions. Implement, test, compare screenshots, and produce exact reports. Continue until working end to end; do not stop after a plan. Do not invent clients, claims or pricing. Higgsfield is already being connected by the user; detect it and use it only where useful and authorized. Do not install MuAPI or other generation dependencies. Begin now.

## Included
- `01_SOURCE_TRUTH_AND_DECISION_REGISTER.md`: verified claims, provisional price bands, source limitations, client questions
- `02_FINAL_CONTENT_AND_SITEMAP.md`: suggested per-page content, navigation, CTAs, all pricing tracks
- `03_MOTION_AND_VISUAL_SYSTEM.md`: distinctive useful interaction and cinematic requirements per route
- `04_CLAUDE_CODE_GOVERNOR_MASTER_PROMPT.md`: gated, test-driven master implementation instructions
- `05_SCREENSHOT_AUDIT_AND_ACCEPTANCE_MATRIX.md`: defects tied to each supplied screenshot and route acceptance criteria
- `reference/`: actual provided images/PDF

## Important
The brochure mentions a circular blue-teal logo while current website uses a different interlocking-blue logo. This package intentionally does not choose one as final. All published prices, service inclusions, legal text, contact details and customer claims need owner approval. The current project repository is not included; this kit is instructions to Claude Code to modify the *existing* site on your computer.
