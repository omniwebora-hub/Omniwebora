# Route storyboards (Gate 2)

Each route: signature interaction (business meaning) · secondary · mobile/no-JS fallback · exit/CTA.

| Route | Signature interaction | Secondary | Fallback | Exit |
|---|---|---|---|---|
| Home | Protected hero + push-in film (camera-matched panels/logo) | Friction → connected workflow switch (H03); evolution selector (H04); live approval demo (H07); scope picker (H09) | Static hero, stacked sections, all states as tabs/lists | Closing pull-back → /contact, /pricing |
| Solutions | Capability map: six stacked layers; focusing one brings its interface forward and updates the explanation | Goal filter highlights the right solutions | Tab list with the same content | Brief CTA |
| Web development | Responsive browser canvas: desktop/tablet/phone widths; four site states (brochure page, enquiry form with validation, catalogue with filter, booking with slot pick) | Six plan table | Same canvas at phone width | Discuss a website |
| Mobile apps | Perspective phone: onboarding → choose service → pick slot → confirmation, with Back/Next and keyboard | Architecture strip (app → API → data → notifications) | Flat phone, same steps | Plan a mobile app |
| Custom software | Module console: pick CRM / Inventory / Billing / Teams; the shared customer/order record highlights wherever it appears | "Show data model" toggle | Same console, stacked | Map your workflow |
| AI & automation | Runner: choose a sample request, run classification → rules → human review (approve/return) → action; audit trail fills | Rules vs AI comparison | Same, steps listed | Explore an automation |
| Cloud & integrations | Topology: select a system to trace its connections; "simulate outage" shows queue + retry + recovered | Capability list | Connection table | Discuss an integration |
| Enterprise | Layer explorer: six architectural layers; selection explains users, data and dependencies | Enterprise tiers + 17-row matrix | Accordion | Discuss enterprise scope |
| Industries | Workstation reconfigures modules and copy per context | Regulated-sector caution | Same, stacked | Talk about your workflow |
| Work | Calm editorial statement, no 3D | Link cards to Concept Lab | — | Concept Lab |
| Concept Lab | Three live demos (commerce, bookings, approvals) with deterministic actions and Reset | Explanation per demo | Same, stacked | Start a project |
| Approach | Seven-stage rail + artefact stage (brief → wireframe → UI → integration map → checklist → monitor → roadmap); click or arrow keys | What you bring / scope handling | Tabs | Start with discovery |
| Pricing | Scope desk: track selector morphs a small architecture diagram; tiers below | Scope guide (category, features, users, integrations, support) → brief summary → contact | All tracks rendered in HTML | Request a detailed proposal |
| About | Documentary artefact desk with gentle depth on pointer | Brochure service index; principles | Static desk | Start a conversation |
| Contact | Project Brief Studio: four steps, live summary card, real submission | Prefill from solution pages (`?service=`) and the pricing scope guide (sessionStorage) | Server-rendered first step; sending requires JavaScript, stated in a `<noscript>` notice | Thank-you page only after real acknowledgement |
