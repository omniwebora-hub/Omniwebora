# OMNIWEBORA — ROUTE-SPECIFIC CREATIVE DIRECTION & INTERACTION STORYBOARDS

## Non-negotiable north star
This is a premium business technology studio, not a Marvel film, a crypto landing page, a fantasy environment or an award-gallery experiment that sacrifices usability. **Use sophisticated motion to explain services.** Visual inspiration: restrained architectural realism, excellent typography, refined material lighting, editorial scale, luxury digital product craftsmanship. Never sacrifice the client's commercial credibility.

Keep the existing approved opening page and successful Higgsfield scroll section(s) UNTOUCHED unless a confirmed bug or explicit visual review requires a small targeted correction. Do not rewrite successful sections to satisfy abstract aesthetics.

## Visual grammar that connects the whole site
- **Material:** realistic ivory stone, clear layered glass, muted sapphire blue, champagne-gold fine edges, midnight-navy anchors. Preserve ample negative space.
- **Typography:** premium editorial serif for major ideas, neutral contemporary sans for explanation/UI. Headline sizes responsive, correct line breaks (avoid words colliding and text running too wide).
- **Object language:** each 3D object has a business meaning: page viewport = website, physical phone = mobile user journey, modular console = software, directional workflow = automation, connecting rails = integrations, stacked system layers = enterprise. Don't scatter anonymous cubes.
- **Movement:** deliberate camera pans, gentle dolly, perspective reveal, local parallax, section-specific transformation. No magical portals, lightning, sci-fi streaks, excessive glow, robots unless a genuinely supported use case.
- **Light:** believable, same direction within a scene; objects cast contact shadows; glass refracts lightly. Gold is a detail, not the whole page.
- **Transitions:** continuity via one shared visual cue (edge, light line, diagram or content anchor), not necessarily one never-ending camera journey.
- **Density:** one dominant immersive moment per route + one secondary contextual interaction; the rest balanced editorial design. Long pricing tables and forms must be easy to use.
- **Truth:** showcases and demos are illustrative unless supplied real client work.

## Higgsfield image & video strategy
Use user's preconnected Higgsfield tools/skills. Verify actual tools, current authentication and credit balance; do not install MuAPI or other asset services. Check source/cost before each batch. Generate targeted high-quality images and short shots ONLY where they improve architectural context or coherent transitions; use DOM/SVG/3D for real interface content. No automatic mass-generation or recurring retries. Keep an asset manifest recording: name, scene, reference used, prompt, generation ID, resolution, dimensions, duration, status, cost if known, license/source, compression, output path, fallback.

**Base prompt formula:**
'Photoreal architectural editorial image of [business-focused subject], restrained modern luxury creative studio design, believable glass and stone, soft natural daylight from [one light direction], navy/ivory/champagne-gold accents, intentional camera perspective, realistic contact shadows, physically plausible materials, high-end product presentation, no legible UI text, no logos embedded, no fantasy machinery, no lightning, no sci-fi portal, editorial commercial design photography.'

**Video formula:**
'Animate the supplied approved first frame into [specific second frame] with a subtle dolly/truck/push, unchanged architecture and object geometry, stable composition, realistic reflections, no identity drift, physically plausible motion, no morphing text, no new objects or rotating camera circus, 4–6 second shot, framing leaves room for real HTML text and controls.'

**Service-specific image direction**
- Website: simple professional desktop monitor in sunlit studio with pristine, controlled screen area (DOM overlay for actual UI).
- Mobile: premium product phone, slight three-quarter view, studio softbox and warm architectural bounce light, screen replaced with real UI.
- Business system: textured modern office context, dashboard framing, no fictional financial data embedded in generated image.
- Automation: tasteful workflow desk with connecting diagram overlays built as DOM/SVG; no anthropomorphic robot.
- Enterprise: restrained exploded architecture modules illustrating system scale, neutral depth, explainable layers.

## Technical motion constraints
- GSAP ScrollTrigger with scrub tied to scroll where useful; disciplined pinning; clean up per route; no nested-pin jitter; semantic fallbacks.
- Use CSS/transforms for small UI; R3F/Three.js only if 3D object must be truly interactive. Higgsfield produces rendered assets, not real-time interactive 3D.
- Stable video poster; locally optimized assets; select media format based on target browsers. Check reverse-scroll; use short sequences or canvas frames only when performance justified. Don't use many uncompressed PNG sequences.
- Respect `prefers-reduced-motion`; keyboard nav, captions if informative, no scroll hijacking, no hidden scrollbars, no keyboard focus traps.
- Good text readability and contrast as priority; never place 30 lines of text over moving busy footage.
- Every scroll scene has an exit, meaningful link, and a mobile-safe alternative.
